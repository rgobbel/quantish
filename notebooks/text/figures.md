# Book figures

*Good and Real* chapter four's figures as live circuits. You can load one, run it, and follow the weights through the gates.

The simulation covers the quantish universe described in Chapter 4 of
*Good and Real: Demystifying Paradoxes from Physics to Ethics* by Gary L. Drescher (MIT Press, 2006), including
Fredkin gates, complex-weighted configuration-space points, and the classic
Einstein-Podolsky-Rosen experiment.

Several kinds of results are available:

- A diagram of the network, with the results filled in after a run
- A graphical trace of how weights evolve through the run of the loaded model
- Tables with exact numeric results from a model's run

Beyond the basic simulation, there are:

- a Monte Carlo simulation, in which a model is run many times, tracing a single execution path depending on the
  probabilities of outputs at each gate, and tabulated to show statistics that imitate the inexact results of real-world experiments
- a simulation of the Einstein-Podolsky-Rosen (EPR) experiment, including results for both Bell's inequality and
  the Clauser–Horne–Shimony–Holt (CHSH) inequality
